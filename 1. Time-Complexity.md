unordered_map
Average Case:
Insertion (insert): O(1)
Deletion (erase): O(1)
Lookup (find): O(1)
Element Access (operator[]): O(1)

Worst Case:
Insertion (insert): O(N)
Deletion (erase): O(N)
Lookup (find): O(N)
Element Access (operator[]): O(N)

std::unordered_map is implemented using a hash table. The average case O(1) complexity relies on a good hash function that distributes keys evenly across the hash table's buckets, minimizing collisions.
The worst-case O(N) complexity occurs when a large number of keys hash to the same bucket, leading to a long linked list or similar structure within that bucket. In such a scenario, operations within that bucket might require traversing a significant portion of the elements, degrading performance to linear time. This can happen with a poorly chosen hash function or specific patterns in the input data that lead to excessive collisions.
